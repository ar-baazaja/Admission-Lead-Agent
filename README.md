# Admission Lead Agent

Interactive demo of an AI admissions assistant for study-abroad consultancies. A student chats on a WhatsApp-style screen; the assistant qualifies the lead, scores it, books a counsellor call and writes a handoff summary with scheduled follow-ups.

Static site, no build step: a single `index.html`.

## Run locally

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy to Vercel

1. Push this repo to GitHub.
2. In Vercel, choose **Add New → Project** and import the repo.
3. Framework preset: **Other**. Leave the build command and output directory empty.
4. Click **Deploy**.

Or from the terminal: `npx vercel --prod`.
